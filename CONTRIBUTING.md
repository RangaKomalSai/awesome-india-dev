# Contribution Guidelines

Thanks for helping build **Awesome India Dev**! The goal is a neutral, high-signal reference for developers building for the Indian market. Please keep the bar high.

## What belongs here

A good entry is a **building block a developer integrates or uses** when building for India — an API, SDK, platform, protocol, or notable developer tool. It should be:

- **Relevant to India** — either India-first, or with meaningful India-specific coverage (UPI, Aadhaar/PAN, GST, Indic languages, etc.).
- **Actively maintained** — a working product or service, not abandoned.
- **Real** — a live homepage or docs page, not a placeholder or a "coming soon".

## What does *not* belong

- Pure marketing pages, affiliate links, or link shorteners.
- Duplicate services already listed.
- Self-promotion without substance (a brand-new product with no users, docs, or track record).
- Non-developer tools (this is a list of building blocks, not general apps).

## How to add an entry

1. **One entry per pull request** where possible — it makes review faster.
2. Use this exact format, placed in the right category and in alphabetical order within that category:

   ```
   - [Name](https://url) - Short, neutral description ending with a period.
   ```

3. Descriptions must be **factual and vendor-neutral** — no superlatives ("best", "leading", "world-class"), no marketing copy. One sentence.
4. Verify the link works and points to the canonical homepage or docs.
5. If a suitable category doesn't exist, propose a new one — and add it to the Contents table of contents too.

## Before you open the PR

- [ ] The entry is in the correct category and alphabetical order.
- [ ] The description is neutral, one sentence, ends with a period.
- [ ] The link works and is canonical.
- [ ] It isn't already listed.
- [ ] Inclusion isn't an endorsement — you've kept the tone objective.

## Fixing things

Broken links, outdated names (e.g. a company rebrand), or dead products — please open a PR or an issue. Maintenance PRs are just as valuable as new entries.
